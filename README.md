## Hi, I'm Pelayo

I'm a full stack developer based in Gijón, Spain. I've spent seven years building .NET and C# applications for insurance companies, and in my spare time I make mobile apps and emulators.

**Projects**

- [**SpeedCube Timer**](https://play.google.com/store/apps/details?id=com.projects.pelayo.speedcubetimer): a speedcubing timer with over 1.7M downloads on Google Play. It has native Android (Kotlin, Java, Compose) and iOS (Swift) apps, plus a .NET 10 backend built with hexagonal architecture, PostgreSQL and Docker. Website: [speedcubetimer.net](https://speedcubetimer.net)
- [**Byrla Boy**](https://play.google.com/store/apps/details?id=com.pelayo.byrla.dmg): a Game Boy, Game Boy Color and Game Boy Advance emulator for Android. The core is written in .NET and compiled with NativeAOT, and the frontend uses Kotlin and Compose. GBA support is powered by [mGBA](https://github.com/pelayin5/mgba).
- [**Byrla NES**](https://play.google.com/store/apps/details?id=com.pelayo.byrla.nes): a NES emulator for Android.

**Open source**

- A few merged bug fixes in [OpenScope](https://github.com/rosenrot00/OpenScope-2C23T), an open firmware for the FNIRSI 2C23T handheld oscilloscope (sample timing, FFT windowing, USB storage).
