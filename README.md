## Hola, soy Pelayo

Desarrollador full stack en Gijón. Llevo siete años trabajando con .NET y C# en aplicaciones para aseguradoras, y en mi tiempo libre hago apps y emuladores.

**Mis proyectos**

- [**SpeedCube Timer**](https://play.google.com/store/apps/details?id=com.projects.pelayo.speedcubetimer): cronómetro de speedcubing con más de 1,7 millones de descargas en Google Play. Tiene app Android (Kotlin, Java, Compose), app iOS (Swift) y un backend en .NET 10 con arquitectura hexagonal, PostgreSQL y Docker. Web: [speedcubetimer.net](https://speedcubetimer.net)
- [**Byrla Boy**](https://play.google.com/store/apps/details?id=com.pelayo.byrla.dmg): emulador de Game Boy, Game Boy Color y Game Boy Advance para Android. El núcleo está escrito en .NET y compilado con NativeAOT, y el frontend en Kotlin y Compose. Para la GBA uso [mGBA](https://github.com/pelayin5/mgba).
- [**Byrla NES**](https://play.google.com/store/apps/details?id=com.pelayo.byrla.nes): emulador de NES para Android.
- [**OpenScope**](https://github.com/pelayin5/OpenScope-2C23T): he contribuido al firmware abierto del osciloscopio portátil FNIRSI 2C23T.

**Con qué trabajo**

C#, .NET, ASP.NET, SQL Server, PostgreSQL, NHibernate, Angular, Kotlin, Swift, Docker, Kubernetes, GitLab CI y Azure DevOps.
